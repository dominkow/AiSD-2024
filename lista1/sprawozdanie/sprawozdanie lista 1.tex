	\section{Algorytm sortowania INSERTION SORT (przez wstawianie)}
	
\large {W podstawowej wersji (bez modyfikacji) algorytmu sortowania przez wstawienie wyróżniamy następujący fragment kodu: }

	\begin{lstlisting}[language=C++, caption={Kod dla funkcji sortującej przez wstawienie}, numbers=left, frame=single, xleftmargin=20pt]
void INSERTION_SORT(int A[], int n) {
	for (int i = 1; i < n; i++) {
		int key = A[i];
		int j = i - 1;
		while (j >= 0 && A[j] > key) {
			A[j + 1] = A[j];
			j--;
		}
		A[j + 1] = key;
		}
	}
	\end{lstlisting}
	
\large {Powyższy fragment kodu zaczyna się od funkcji for, która przechodzi kolejno po każdym elemencie tablicy \(A\). Naszą iterację zaczynamy od drugiego elementu tablicy (z indeksem \(1\)) (zakładając, że \(0\) jest już posortowany). Zmienna \(key\) umożliwia przechowanie wartości wstawianego elementu zapobiegając  nadpisaniu oraz pozwalając na porównywanie tej wartości z kolejnymi elementami posortowanego ciągu. Gdy napotkany element w posortowanej części jest większy od wstawianego, przesuwamy go o jedną pozycję w prawo, aby zrobić miejsce na wstawienie nowego elementu. Jeśli element w posortowanej części jest mniejszy lub równy wstawianemu, wówczas zapisujemy wstawiany element na kolejnej pozycji.}
		
\newpage

\large {Modyfikacja INSERTION SORTA polega na wstawianiu "na raz" dwóch kolejnych elementów tablicy. Zatem duża część kodu działa w dość analogiczny sposób.}



\begin{lstlisting}[language=C++, caption={Fragment 1 funkcji sortującej przez wstawienie z modyfikacją}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void INSERTION_SORT_MOD(int A[], int n) {
	for (int s = 1; s < n - 1; s += 2) {
		int pierwszy = A[s];
		int drugi = A[s + 1];
		if (pierwszy > drugi) {
			swap(pierwszy, drugi);
		}
		int k = s - 1;
		while (k >= 0 && A[k] > pierwszy) {
			A[k + 1] = A[k];
			k--;
		}
		A[k + 1] = pierwszy;
		A[k + 2] = drugi;
	}
}

\end{lstlisting}

\large{Pętla zaczyna się od indeksu \(1\) i iteruje z krokiem \(+2\), co pozwala jednocześnie rozpatrywać dwie wartości – \(pierwszy\) i \(drugi\). Następie porównujemy je za pomocą funkcji if i jeśli \(pierwszy\) jest większy zamieniamy miejscami. Funkcja while działa już na tej samej zasadzie co w kodzie bez modyfikacji.}

\newpage

\begin{lstlisting}[language=C++, caption={Fragment 2 funkcji sortującej przez wstawienie z modyfikacją}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
if (n % 2 == 0) {
	int ostatni = A[n - 1];
	int k = n - 2;
	while (k >= 0 && A[k] > ostatni) {
		A[k + 1] = A[k];
		k--;
	}
	A[k + 1] = ostatni;
}
	
\end{lstlisting}

\large{Przedstawiona modyfikacja jednak wymaga rozważenia przypadku, czy tablica \(A\) ma długość parzystą, czy nieparzystą. Problem pojawia się gdy \(n\) jest parzyste, gdyż ostatni sortowany element nie ma pary (\(ostatni = A[n - 1]\)). Dla \(k\) przypisujemy przedostatni indeks tablicy, które też będzie miejscem rozpoczęcia wstawiania elementu \(ostatni\). Pętla \(while\) działa identycznie jak ta w podstawowym INSERTION SORCIE, z uwagą, że naszym \(key\) jest \(ostatni\).}

	\section{Algorytm sortowania MERGE SORT (przez scalenie)}
	
\begin{lstlisting}[language=C++, caption={Fragment 1 funkcji sortującej przez scalenie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void MERGE(int A[], int p, int s, int k) {
	int n1 = s - p + 1;
	int n2 = k - s;
	int L[n1 + 1];
	int P[n2 + 1];
	L[n1] = INT_MAX;
	P[n2] = INT_MAX;
}
\end{lstlisting}

\large{W przypadku MERGE SORTA ważną rolę odgrywa funkcja MERGE, na której na dobrą sprawę zbudowany jest MERGE SORT. MERGE przyjmuje cztery argumenty: \(p\) - początek, \(s\) - środek oraz \(k\) - koniec. Za ich pomocą dzielimy tablicę na dwie części: lewą (\(n1 = s - p + 1\)) oraz prawą (\(n2 = k - s\)). Definiujemy funkcje pomocnicze L i P o pojemności kolejno \(n1 + 1\) oraz \(n2 + 1\). Następnie ustawiamy ostatni element na "napewno większy" od największego elementu tablicy \(A[]\).}

\begin{lstlisting}[language=C++, caption={Fragment 2 funkcji sortującej przez scalenie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
int i = 0;
int j = 0;
for (int l = p; l <= k; l++) {
	if (L[i] <= P[j]) {
		A[l] = L[i];
		i++;
	} else {
		A[l] = P[j];
		j++;
	}
}
\end{lstlisting}
\large{Po przypisaniu z lewej części do zmiennej \(L\) i z prawej części \(P\) resetujemy wskaźniki \(i\) oraz \(j\) (które wskazują naszą pozycję w kolejno w L i P).
	
Instrukcja \(if (L[i] \leq P[j])\) sprawdza, czy bieżący element z \(L\) jest mniejszy lub równy bieżącemu elementowi z \(P\). \\
Jeśli tak, to mniejszy element \(L[i]\) jest wstawiany do tablicy \(A[l]\), a wskaźnik \(i\) jest zwiększany o \(1\), by przejść do następnego elementu w \(L\). \\
Jeśli nie, to mniejszy element \(P[j]\) jest kopiowany do \(A[l]\), a wskaźnik \(j\) jest zwiększany o \(1\), by przejść do następnego elementu w \(P\).}
\\

\begin{lstlisting}[language=C++, caption={Fragment 3 funkcji sortującej przez scalenie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void MERGE_SORT(int A[], int p, int k) {
	if (p < k) {
		int s = (p + k) / 2;
		MERGE_SORT(A, p, s);
		MERGE_SORT(A, s + 1, k);
		MERGE(A, p, s, k);
	}
}
\end{lstlisting}
\large{Po przeanalizowaniu funkcji MERGE, możemy przejść do funkcji MERGE SORT, która wylicza srodek tablicy i wywołuje kolejno sortowanie z lewej strony, prawej strony po czym scala obie strony.}

\begin{lstlisting}[language=C++, caption={Fragment 1 funkcji sortującej przez scalenie z modyfikacją}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void MERGE_MODYFIKOWANY(int A[], int p, int s1, int s2, int k) {
	int n1 = s1 - p + 1;
	int n2 = s2 - s1;
	int n3 = k - s2;
	int L[n1 + 1];
	int S[n2 + 1];
	int P[n3 + 1];
	L[n1] = INT_MAX;
	S[n2] = INT_MAX;
	P[n3] = INT_MAX;
}
\end{lstlisting}
\large{Modyfikacja MERGE SORTA polegała na podzieleniu tablicy na trzy części zamiast dwóch, wiec cały kod opiera się i ma bardzo podobną budowę do podstawowego MERGE SORTA. Zamiast dwóch części tworzymy trzy: \\
	 \(n1 = s1 - p + 1\)\\
	 \(n2 = s2 - s1\)\\ 
	 \(n3 = k - s2\)\\
	  a jako, że rozdzielamy tablicę. Pozostała reszta MERGA MODYFIKOWANEGO jak i MERGE SORTA MODYFIKOWANEGO przebiega bardzo podobnie.}

	\section{Algorytm sortowania HEAPSORT (przez kopcowanie)}


\large{Przy HEAPSORCIE podobnie jak przy MERGESORCIE ciekawe rzeczy dzieją się w funkcjach pomocniczych. Przeanalizujmy zateam HEAPIFY (na kopcach binarnych).}

\begin{lstlisting}[language=C++, caption={Fragment 2 funkcji sortującej przez kopcowanie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
int LEWA(int i) {
	return 2 * i;
}
int PRAWA(int i) {
	return 2 * i + 1;
}
\end{lstlisting}

\large{Kod powyżej definiuje pozycje lewego "dziecka" oraz "prawego" dziecka w kopcu binarnym.}

\begin{lstlisting}[language=C++, caption={Fragment 1 funkcji sortującej przez kopcowanie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void HEAPIFY(int A[], int i, int n) {
	int l = LEWA(i);
	int p = PRAWA(i);
	int naj = i;
		
	if (l < n && A[l] > A[i]) {
		naj = l;
	}
		
	if (p < n && A[p] > A[naj]) {
		naj = p;
	}
		
	if (naj != i) {
		swap(A[i], A[naj]);
		HEAPIFY(A, naj, n);
	}
}
	
\end{lstlisting}
\large{Argumentami jest tablica \(A[]\), która reprezentuje nasz "kopiec", \(i\) która oznacza indeks od którego zaczynamy "naprawę kopca" oraz \(n\) odpowiedzialna za długość tablic.}

\begin{itemize}
	\item $l = \text{LEWA}(i)$ \\
	Oblicza indeks lewego dziecka węzła $i$ i przypisuje go do zmiennej $l$. Używa funkcji \texttt{LEWA}, która zwraca $2 \cdot i$.
	
	\item $p = \text{PRAWA}(i)$ \\
	Oblicza indeks prawego dziecka węzła $i$ i przypisuje go do zmiennej $p$. Używa funkcji \texttt{PRAWA}, która zwraca $2 \cdot i + 1$.
	
	\item $naj = i$ \\
	Ustawia zmienną $naj$ (przechowującą indeks największego elementu) na $i$. Zakładamy na początku, że węzeł $i$ jest największy wśród siebie i swoich dzieci.
\end{itemize}
\begin{itemize}
\item $ \text{if} \ (l < n \ \text{and} \ A[l] > A[i]) \ {\{} \ naj = l; \ {\}}$ \\
Sprawdza, czy lewe dziecko $l$ znajduje się w zakresie kopca ($l < n$), a wartość w tablicy $A$ pod indeksem $l$ jest większa niż wartość w $A[i]$. \\
Jeśli oba warunki są spełnione, to zmienna $naj$ zostaje ustawiona na $l$, co oznacza, że największy element jest teraz na pozycji lewego dziecka.
\end{itemize}

\large{To samo robimy dla p, tylko zmieniamy \(A[i]\) na \(A[naj]\), gdyż w naturalny sposób przez pierwszego ifa wartość największa mogła się zmienić.}

\large{Na sam koniec sprawdzamy, czy znaleźliśmy element większy od naszego początkowego, jeśli tak to zamieniamy miejscami je miejscami. Jeszcze wywołujemy HEAPIFY rekurencyjnie na poddrzewie naj, aby upewnić się, że poddrzewo również spełnia własność kopca.}
\\
\begin{lstlisting}[language=C++, caption={Fragment 2 funkcji sortującej przez kopcowanie bez modyfikacji}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
void BUILD_HEAP(int A[], int n) {
	for (int i = n / 2 - 1; i >= 0; i--) {
		HEAPIFY(A, i, n);
	}
}

void HEAPSORT(int A[], int n) {
	BUILD_HEAP(A, n);
	
	for (int i = n - 1; i >= 1; i--) {
		swap(A[0], A[i]);
		n--;
		HEAPIFY(A, 0, n);
	}
}
\end{lstlisting}

\large{W BUILD HEAPIE inicjujemy pętlę for, która iteruje od środkowego elementu tablicy \((n / 2 - 1)\) wstecz do pierwszego elementu (indeks \(0\)). Dzięki takiemu iterowaniu nasza funkcja HEAPIFY może poprawnie naprawić kopiec dla każdego poddrzewa, budując kopiec od dołu do góry.}
\\

\large {W HEAPSORCIE: }
\begin{itemize}
\item $ \text{for} \ (i = n - 1; i \geq 1; i--) \ {\{}$ \\
Inicjuje pętlę, która iteruje od ostatniego elementu tablicy $A[n - 1]$ wstecz do drugiego elementu $A[1]$. \\
przesuwając największy element kopca do jego końcowej pozycji.

\item $ \text{swap}(A[0], A[i]);$ \\
Zamienia miejscami elementy $A[0]$ (korzeń kopca, największy element) oraz $A[i]$ (bieżący koniec kopca), dzięki czemu największy element trafia na właściwe miejsce. 
\end{itemize}

\begin{lstlisting}[language=C++, caption={Fragment 1 funkcji sortującej przez kopcowanie z modyfikacją}, numbers=left, frame=single, xleftmargin=20pt, xrightmargin = 1pt]
int LEWA_T(int i) {
	return 3 * i;
}
int SRODEK_T(int i) {
	return 3 * i + 1;
}
int PRAWA_T(int i) {
	return 3 * i + 2;
}
void HEAPIFY_T(int A[], int i, int n) {
	int l = LEWA_T(i);
	int s = SRODEK_T(i);
	int p = PRAWA_T(i);
	int naj = i;
	if (l < n && A[l] > A[i]) {
		naj = l;
	}
	if (s < n && A[s] > A[naj]) {
		naj = s;
	}
	if (p < n && A[p] > A[naj]) {
		naj = p;
	}
	if (naj != i) {
		swap(A[i], A[naj]);
		HEAPIFY_T(A, naj, n);
	}
}
\end{lstlisting}

\large{Modyfikacja algorytmu HEAPSORT miała polegać na użyciu kopców binarnych kopce ternarne. Ta midyfikacja najbardziej wpływa na HEAPIFY, gdyż oprócz lewego oraz prawego "dziecka" mamy również środkowe. Tak więc teraz:\\
funkcja \(LEWA T\) zwraca \(3 * i\)\\
funkcja \(SRODEK T\) zwraca \(3 * i + 1\)\\
funkcja \(PRAWA T\) zwraca \(3 * i + 1\)\\
Więc w zmodyfikowanej wersji HEAPSORTA, w HEAPIFY występuje dodatkowa zmienna s, która przy porównywaniu  wartości dodaje jedną dodatkową pętle if.}
